# TailView icon

- `tailview.png`: transparent original generated with the built-in imagegen tool.
- `tailview.ico`: the same design converted to ICO at 16, 24, 32, 48, 64, 128 and 256 pixels.
- `tailview.rc`: Windows icon and product version resources.
- Accent: fox orange `#F47A32`; inner shade `#C65325`; ivory tip `#FFF1DC`.

Generation prompt:

> Use case: logo-brand. Asset type: TailView desktop application icon, square transparent PNG. Create one bold minimal fox TAIL (no fox face, no ears, no whole animal). The single fluffy tail folds down into a clear capital V silhouette: a tapered upper-left root slopes down to a rounded bottom point and then a much fuller bushy tail sweeps up to the upper-right. The upper-right bushy tip is ivory white with a jagged fur boundary. Fox orange #F47A32, deeper burnt orange #C65325 on the inner bend, ivory #FFF1DC tip. Flat crisp vector-like shapes, restrained two-tone shading, strong legibility at 32 pixels, centered, generous 12 percent transparent padding. No text, no letters drawn separately, no badge, no border, no shadow, no background, no watermark. The tail itself must suggest V.
